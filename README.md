# Chrome Extension

A simple Chrome extension for saving text and web pages for quick access.

---

## Features

- **Save Input** – Saves the text entered in the input field for later access.
- **Save Tab** – Saves the URL of the currently active browser tab.
- **Delete All** – Removes all saved data. To prevent accidental deletion, this action requires a **double-click** on the button.

---

## Installation

1. Download or clone this repository.

   ```bash
   git clone https://github.com/your-username/chrome_extension.git
   ```

   Or click **Code → Download ZIP**, then extract the ZIP file.

2. Open Google Chrome(or any Chromium-based browser).

3. Navigate to:

   ```
   chrome://extensions/
   ```

4. Enable **Developer mode** using the toggle in the top-right corner.

5. Click **Load unpacked**.

6. Select the project folder that contains the `manifest.json` file.

7. The extension will now appear in your Chrome toolbar. If it doesn't, click the **Extensions** icon and pin it for quick access.

---

## How to Use

- Type any text into the input field and click **Save Input**.
- Click **Save Tab** to save the URL of the currently active browser tab.
- Double-click **Delete All** to remove all saved items.
